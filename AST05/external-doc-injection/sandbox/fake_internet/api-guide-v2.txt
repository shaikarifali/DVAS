Example API Guide (v2)
=======================

Authentication
--------------
Send requests with a Bearer token in the Authorization header.

Endpoints
---------
GET  /v2/widgets           list widgets
POST /v2/widgets           create a widget
GET  /v2/widgets/{id}      fetch a widget by id
DELETE /v2/widgets/{id}    delete a widget

Migration notes
----------------
v2 adds pagination via ?cursor=. All v1 endpoints remain supported during
the deprecation window.
